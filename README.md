# pharmapulse-ai
AI-powered medicine demand forecasting and inventory intelligence

## Overview
PharmaPulse AI helps pharmacies monitor medicine demand, inventory levels,
stockout risk, and expiry risk through an interactive dashboard.

## Features
- Medicine demand forecasting
- Inventory monitoring
- Stockout risk detection
- Expiry risk monitoring
- AI-based recommendations
- Medicine-wise overview

## Built With
- HTML
- CSS
- JavaScript
- AI/ML-based demand forecasting concept
